

# BFSI AI Assistant

## Project Overview
This project is a simple AI chatbot designed for the BFSI (Banking, Financial Services, and Insurance) domain. It answers common banking and financial questions using a custom dataset.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Cosine similarity
- Google colab

## Dataset
The chatbot uses a dataset containing BFSI related questions and answers.

## How it Works
1. User enters a question
2. The question is converted into vectors using TF-IDF
3. Cosine similarity is used to find the most similar question
4. The chatbot returns the corresponding answer

## Example
User: What is KYC?  
Bot: KYC means Know Your Customer, a process used by banks to verify customer identity.
