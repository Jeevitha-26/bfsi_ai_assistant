BFSI AI Assistant

Overview

This project is a simple AI assistant developed for the BFSI (Banking, Financial Services and Insurance) domain. It answers common banking-related questions using a dataset of predefined questions and answers.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Google Colab

Dataset

The dataset contains around 150 banking-related questions and answers used to train the chatbot.

How It Works

The chatbot matches the user query with the dataset and returns the most relevant answer.
